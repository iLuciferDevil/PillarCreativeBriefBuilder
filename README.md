# Pillar Performance Creative Brief Builder

A lightweight internal tool for Growth to create decision-ready performance creative briefs for Brand / Creative.

## Workflow
- Growth owns the business problem, hypothesis, creative requirement, test design, and measurement plan.
- Data validates baselines and performance evidence where needed.
- Brand / Creative owns the creative solution and brand execution.
- Growth completes the post-test readout after sufficient data is available.

## Deploy
Static HTML. Deploy directly to Vercel with no build step.
